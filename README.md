# Chaos Control — PS02: Sabotage the System

Two-player local asymmetric arena game for Unreal Engine 5 (C++).
One player is the **Runner** (collect 3 energy cores, reach the exit). The other is the **Saboteur** (trigger lasers, moving platforms and stun traps with limited energy).
Roles swap after each round. The higher total score after 2 rounds wins, and equal scores are a draw.

> **Status:** builds cleanly with **UE 5.8.4** and the VS 2026 compiler (MSVC 14.51).
> Unit tests 3/3 and the gameplay self-test 237/237 checks pass (4 full matches across all 3 arenas, including a draw).
> A manual two-player session is still needed for AC-01.
> Visual overhaul verified with real rendering: 12 full matches passed with no crashes, and every screen was reviewed from screenshots.

## Requirements

1. **Unreal Engine 5** — install the newest 5.x version from the Epic Games Launcher (Unreal Engine → Library → +).
   On first open, choose that version if asked, or right-click `ChaosControl.uproject` → *Switch Unreal Engine version*.
2. **Visual Studio 2022 or 2026** (Community edition is free) with these workloads:
   - *Game development with C++*
   - *Desktop development with C++*

   Also install a Windows 11 SDK, the .NET Framework 4.8.1 SDK, and the
   *MSVC v143 – VS 2022 C++ x64/x86 build tools* component, which older engine versions need.
   You only use Visual Studio as the compiler; edit the code in VS Code.

No marketplace assets are needed. Geometry uses `/Engine/BasicShapes`, and the four master materials in
`Content/Materials` are generated by `Scripts/create_materials.py`. The Python Editor Script plugin is enabled for that, editor only.

Alternatively, double-click `ChaosControl.uproject` and answer **Yes** to rebuild modules. Then press **Play** (use *Standalone Game*, because Esc ends a PIE session).

### What the self-test does (`-ChaosAutoTest`)

`RunTests.ps1` launches the game headless with `-ChaosAutoTest`. It plays **4 complete matches** through the real gameplay code, then prints `CHAOS AUTOTEST RESULT: PASSED/FAILED` and quits.

- **Neon Grid:**
  - Checks every ability's cost, cooldown and insufficient-energy rejection.
  - Checks that the laser blocks, the platform moves and the stun trap immobilises the Runner.
  - Checks that every mechanism resets itself.
- **All three arenas:**
  - Cores are collected through their real overlap triggers.
  - The exit stays locked until all three cores are collected.
  - No duplicate or wrong-role scoring.
  - The Runner wins on reaching the exit; the Saboteur wins when the timer expires.
  - The timer stops when a round ends.
  - Roles swap with scores preserved, and the arena, energy, cooldowns and timer reset.
  - The final winner is correct, and *Play Again* and *Main Menu* work.
- **Draw match:** checks that equal scores produce a draw.

Each check is logged as `[PASS]`/`[FAIL]` with its AC number in `Saved/TestLogs/AutoTest.log`.

## Controls

| | Player 1 | Player 2 |
|---|---|---|
| Move | W A S D | Arrow keys |
| Jump | Space | Right Ctrl |
| Interact (Runner) / cycle mechanism (Saboteur) | E | Enter |
| Trigger selected mechanism (Saboteur) | Q | Right Shift |

- **P / Esc:** pause (Resume, Restart Match, Controls, Main Menu).
- **Menus:** mouse, or Up/Down + Enter.
- **Rebinding:** keys can be changed in `Config/DefaultGame.ini`.
- **Sticky Keys:** pressing Shift 5 times opens Windows' Sticky Keys prompt. Turn off its shortcut before a session.

Both players share one keyboard and one overhead camera. The single PlayerController reads the whole keyboard and routes each player's keys to their avatar. Avatars pass through each other, so the Saboteur cannot body-block a door.

## How it plays

- **Runner:**
  - Touch the 3 glowing cores. The exit gate turns from red to green.
  - Walk into the gate before 1:30 runs out.
  - Falling into a pit sends you back to your spawn point.
- **Saboteur:**
  - Interact cycles between Laser, Platform and Stun.
  - Sabotage triggers the idle mechanism of that type **nearest to you**. The HUD marks it with `[ TARGET ]`, so where you stand matters.
  - **Energy:** 100, with no regeneration. Costs are Laser 35, Platform 25, Stun 40.
  - **Cooldowns:** 8 s, 6 s and 10 s.
- **Mechanisms:**
  - **Laser:** blocks a doorway for 4 s.
  - **Platform:** a pit bridge that swings back and forth for 6 s, then glides home.
  - **Stun pad:** flashes for 0.6 s, then immobilises the Runner for 2 s, at most once per activation. 1.5 s immunity follows.
- **Scoring:**

  | Event | Points |
  |---|---:|
  | Energy core | 100 |
  | Runner reaches the exit | 300 + 200 win bonus |
  | Saboteur holds until time runs out | 300 |

All values are in `Config/DefaultGame.ini`. Edit them and restart; no recompile is needed.

## Arenas

All three arenas share the same footprint and modular pieces, and all are built at runtime by `AChaosArenaManager`.

| Arena | Layout | Mechanisms |
|---|---|---|
| **Neon Grid** | Wall with 2 doors, one trench, low cover | 2 lasers, 1 platform, 2 stun pads |
| **Reactor Run** | Reactor block splits two lanes; each lane crosses a pit | 2 lasers, 2 platforms, 3 stun pads |
| **Chaos Core** | 5 narrow doors on two dividers, central chasm, side passages, pillars | 3 lasers, 1 platform, 3 stun pads |

Every arena keeps at least one open route while any single mechanism is active. Pits are 550 cm wide, more than a running jump, so the platform is the only way across a pit.

## Visual system

- **Materials** (`Content/Materials`, generated by `Scripts/create_materials.py`):
  - `M_ChaosSurface`: PBR, world-aligned panels, seams with optional glow, per-panel tone variation.
  - `M_ChaosEmissive`: animated neon with pulse and travelling bands.
  - `M_ChaosEnergy`: additive shields and beams with rim glow and scanlines.
  - `M_ChaosHazard`: warning stripes.
  - Every material has a `Color` parameter.
- **Lighting:**
  - Lumen global illumination and reflections (software tracing).
  - One shadowing key light, a tinted sky light and height fog.
  - Arena accent point lights.
  - Manual exposure (`ExposureCompensation` in `DefaultGame.ini`) and restrained bloom.
- **Arena themes:**
  - Neon Grid: cool training facility with a cyan grid.
  - Reactor Run: warm industrial, with a caged reactor, cooling towers and amber hazard language.
  - Chaos Core: glossy graphite, with a magenta energy core suspended in the chasm.
  - Every arena sits on a catwalk ring above a lower facility level that is visible through the pits.
- **Performance:**
  - Static scenery is instanced (about 190–230 pieces in a few dozen draw batches).
  - Point lights don't cast shadows.
  - Effects are short-lived and only spawned on events.
- **No audio:** the project has no audio assets, and none were downloaded.
